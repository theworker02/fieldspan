# fieldspan

Field timestamps and span durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/fieldspan/

## Install / run

```bash
git clone https://github.com/theworker02/fieldspan.git
cd fieldspan
node src/cli.js
node --test
```
